# El Arte de la Terminal
![portada](https://github.com/ByChokeYT/El_Arte_de_la_Terminal/blob/main/Recursos/El%20arte%20de%20la%20terminal.gif?raw=true)
[![github](https://img.shields.io/badge/GitHub-ByChoke-181717?style=for-the-badge&logo=github&logoColor=white&labelColor=101010)](https://github.com/ByChokeYT)

La fluidez en el terminal es una destreza a menudo abandonada y considerada arcaica, pero ésta mejora tu flexibilidad y productividad como ingeniero de formas obvias y sutiles. Esta es una selección de notas y consejos para usar el terminal que encontramos útiles al trabajar en Linux. Algunos consejos son elementales y algunos bastante específicos, sofisticados y oscuros.

Este trabajo es el resultado de mucho tiempo y dedicación [![PayPal](https://img.shields.io/badge/PayPal-00457C?style=for-the-badge&logo=paypal&logoColor=white)](https://paypal.me/bychoke?country.x=CL&locale.x=es_XC)

# Temario del Curso

Haz clic en cualquiera de los temas a continuación para ver el contenido detallado:

- 📖 **[Meta](temas/meta.md)**: Alcance, objetivos de la guía y herramientas sugeridas.
- ⚙️ **[Fundamentos](temas/fundamentos.md)**: Conocimientos esenciales de Bash, Vim, man, redirecciones, SSH, permisos y redes.
- ⌨️ **[De uso diario](temas/uso_diario.md)**: Atajos de teclado en Bash, alias, subshells, expansión de variables y trucos útiles cotidianos.
- 📊 **[Procesamiento de archivos y datos](temas/procesamiento_archivos_y_datos.md)**: Búsqueda avanzada (`find`/`ag`), conversión de formatos (JSON/YAML/CSV), `sort`, `uniq`, `awk`, `sed`, diff y patch.
- 🐛 **[Depuración del sistema](temas/depuracion_sistema.md)**: Diagnóstico de hardware, red, CPU, memoria, procesos, JVM y puertos (`htop`, `ss`, `lsof`, `/proc`).
- ⚡ **[One-liners](temas/one_liners.md)**: Líneas de comandos combinadas y potentes listas para usar.
- 👻 **[Obscuro pero útil](temas/obscuro_pero_util.md)**: Herramientas del sistema menos conocidas pero de gran utilidad (`sponge`, `dd`, `comm`, `units`).
- 🚀 **[Terminal Moderna (Modern Unix)](temas/terminal_moderna.md)**: Alternativas modernas como `bat`, `eza`, `fd`, `ripgrep`, `zoxide`, emuladores rápidos y prompts dinámicos.
- 🍎 **[Solo para OS X](temas/solo_os_x.md)**: Consejos y herramientas específicas para macOS.
- 💻 **[Solo para Windows](temas/solo_windows.md)**: Configuración y uso de entornos Unix en Windows (WSL, Cygwin, MinGW).
- 🔗 **[Más recursos](temas/mas_recursos.md)**: Enlaces a repositorios, guías de estilo estricto y linters externos.
- ⚠️ **[Advertencia](temas/advertencia.md)**: Consejos sobre la legibilidad y la responsabilidad al escribir scripts en Bash.
