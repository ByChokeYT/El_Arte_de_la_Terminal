Scripting Avanzado y Automatización (Funciones, Arrays, cron)

Aprende a estructurar tu código, manejar listas indexadas y programar tareas periódicamente.

Funciones

Reutiliza código de forma estructurada:

respaldar() {
    local ip=$1
    echo "Respaldando base de datos de: $ip"
}
respaldar "192.168.1.150"

Arrays (Arreglos)

Maneja listas indexadas en una única variable:

servidores=("10.0.0.1" "10.0.0.2")
echo "Primer servidor: ${servidores[0]}"

Automatización con cron

Ejecuta tus scripts periódicamente programándolos en el crontab (crontab -e).

0 0 * * 0 /ruta/al/script.sh # Ejecuta cada domingo a la medianoche
